Each plan can set three limits, or leave any of them Unlimited:

| Limit | What counts |
|---|---|
| Active leads | Open leads: New, Shortlisted, Applied, Interview and Offer Received. Stale leads count too, because they're still open. Closed and discarded don't |
| Résumé uploads | Résumés stored at once |
| Add with AI per month | Times the user creates a lead with Add with AI this calendar month |

Users see their usage in **Settings → Plan**. An unlimited limit shows just "Unlimited", with no count.

## At the active-lead limit

- Adding a lead by hand is blocked with "Your plan allows N active leads. Archive leads you're done with, or upgrade your plan for unlimited leads."
- New jobs from forwarded alerts aren't added. Alerts for jobs the user already has still refresh them.
- The user gets a "Lead limit reached" notification, at most once a day.

At the résumé limit, uploading another says "Your plan allows N résumés. Delete one first, or upgrade your plan to add more."

Closing or discarding leads frees room right away, and so do the automatic cleanup rules.
